# Maqueta: nueva web para despacho de abogados

Propuesta de diseño ilustrativa para el rediseño de la web de un despacho de
abogados en San Fernando (Cádiz). **No es la web oficial del despacho.**

- `index.html`: portada.
- `servicio-despidos.html`: ejemplo de página de servicio.
- `estilos.css`: estilos compartidos.

Nombres de abogados, números de colegiado, reseñas y número de WhatsApp son
marcadores pendientes de confirmar. El formulario no envía datos.

Fotografías: [Unsplash](https://unsplash.com/license), uso libre.
